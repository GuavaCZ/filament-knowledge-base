# Code highlighting

Fenced code blocks are highlighted with Phiki:

```php
use Guava\FilamentKnowledgeBase\Plugins\KnowledgeBasePlugin;

$panel->plugins([
    KnowledgeBasePlugin::make(),
]);
```

composer require guava/filament-knowledge-base
