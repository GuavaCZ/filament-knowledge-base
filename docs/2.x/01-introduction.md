# Introduction

Knowledge Base allows you to create markdown powered knowledge base panels in your filament app.

Unlike most other filament packages, this package provides two separate plugins instead of a single one:

- The `KnowledgeBasePlugin` is for the panel(s) you want to turn into a knowledge base.
- The `KnowledgeBaseCompanionPlugin` is for your regular filament panels, to add supporting features and integrations with your knowledge base panel(s). For example, this lets you access snippets of your documentation pages via modals right inside your regular panels.

To learn more about each plugin, please refer to their own documentation pages.

## Version compatibility

| Filament version | Plugin version |
|------------------|:--------------:|
| 3.x              |      1.x       |
| 4.x              |      2.x       |
| 5.x              |      3.x       |

Version 2.x is built for filament 4.
